# Behavior Spec

本文规定 ComicPlate 的行为边界。后续写代码时，以这里为准；如果代码和这里冲突，先改文档或先改代码，但不能心里默认。

## 0. 只读原则

ComicPlate MVP 是只读阅读器。

允许写入：

- ComicPlate 自己的设置文件。
- ComicPlate 自己的阅读进度文件。
- ComicPlate 自己的最近打开记录。
- ComicPlate 自己的日志或缓存。

禁止写入：

- 删除用户图片。
- 移动用户图片。
- 重命名用户图片。
- 修改压缩包内容。
- 覆盖原图。
- 写回元数据。

右键菜单、快捷键、侧栏和任何工具按钮都必须遵守这个原则。

## 1. Book 身份

本文中的 Book 是工程统一概念，对用户来说就是“当前打开的一本漫画/一个可预览范围”。

- 文件夹 = 一个可阅读单元，可以作为一本 Book 打开。
- ZIP/CBZ = 一个可阅读单元，可以作为一本 Book 打开。
- 单张图片可以作为一本 Book 打开。
- 单张图片 = 一个单页 Book，居中显示。
- Book 里面的图片 = Page。
- ComicPlate 不识别漫画作品，也不维护漫画库；它只把用户选择的路径解释成线性 Page 流。

- 文件夹 Book ID：规范化后的绝对路径。
- ZIP/CBZ Book ID：规范化后的绝对路径。
- MVP 不使用内容 hash。
- 如果同一路径的内容变化，仍视为同一本书，但打开时重新扫描页面列表。
- 如果上次记录的页码超过新页面数量，恢复到最后一页。

## 1.1 可阅读单元

可阅读单元是用户主动选择打开的路径。ComicPlate 对它的行为是 **Open as Book**。

当用户选择一个文件夹时：

1. ComicPlate 把这个文件夹作为一个 Book。
2. 默认递归扫描其中的支持格式图片。
3. 不把子文件夹识别为独立 Book。
4. 不把子文件夹本身显示为页面。
5. 按相对路径自然排序，生成线性 Page 流。
6. 如果文件夹里没有可读图片，显示空状态。

当用户选择一个 ZIP/CBZ 时：

1. ComicPlate 把这个压缩包作为一个 Book。
2. 读取压缩包内支持格式图片。
3. 不解压到用户目录，也不修改压缩包内容。
4. 按压缩包内逻辑路径自然排序，生成线性 Page 流。

当用户选择一个包含多个卷册压缩包的文件夹时：

- MVP 把该文件夹中的 ZIP/CBZ 按路径自然排序后串联进同一本 Book。
- 文件夹普通图片和 ZIP/CBZ 内图片可以合并到同一个 Page 流。
- RAR/CBR/7z/CB7 串联属于 V1 格式扩展。
- 这仍然是“用户打开的文件夹 = 一本 Book”，不是书架扫描。

压缩包套压缩包不支持：如果 ZIP/CBZ 内还有 ZIP/CBZ/RAR/7z 等压缩包，MVP 直接忽略，不把它们当作页面或子书籍。

ComicPlate 不提供书架排序、过滤、分组配置。用户通过文件系统管理自己的漫画内容。

## 2. 支持图片格式

MVP 支持：

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.bmp`
- `.gif`

MVP 行为：

- 扩展名大小写不敏感。
- `.gif` 只显示第一帧，不播放动画。
- 非图片文件忽略，不提示。
- 图片扩展名正确但解码失败，显示错误占位页，并允许继续翻页。

## 3. 打开文件夹 Book

当用户打开一个文件夹 Book 时：

1. MVP 默认递归读取当前文件夹及所有子文件夹内的文件。
2. 后续可以提供“不递归”选项，但这不是当前目标。
3. 过滤支持的图片扩展名。
4. 不把子文件夹显示为页面。
5. 对结果使用自然排序，升序。
6. 如果没有图片，显示空状态：“这个文件夹里没有可阅读的图片”。

MVP 默认：

- 默认递归扫描 Book 内部章节目录。
- 按相对路径自然排序，例如 `Chapter 1/001.jpg` 早于 `Chapter 2/001.jpg`。

自然排序要求：

- `1.jpg, 2.jpg, 10.jpg` 的顺序应为 `1, 2, 10`。
- 排序应尽量接近系统文件管理器直觉。
- 同名不同扩展名时，按完整文件名稳定排序。

## 4. 打开 ZIP/CBZ Book

当用户打开 ZIP/CBZ Book 时：

1. 枚举压缩包内所有条目。
2. 忽略目录条目。
3. 过滤支持的图片扩展名。
4. 忽略非图片文件。
5. 默认包含压缩包内子目录中的图片。
6. 按条目完整路径自然排序。
7. 路径分隔符统一处理为 `/` 后排序。
8. 忽略压缩包内的压缩包条目，不做嵌套读取。

错误边界：

- ZIP 文件打不开：显示错误状态，不崩溃。
- ZIP 里没有图片：显示空状态。
- 单张图片解码失败：显示错误占位页，可继续翻页。
- 密码 ZIP：MVP 不支持，显示“不支持加密压缩包”。

## 4.1 文件夹内 ZIP/CBZ 合集

当用户打开一个文件夹 Book 时，MVP 同时扫描该文件夹及子文件夹中的 `.zip` 和 `.cbz`。

排序规则：

- 文件系统图片使用相对路径参与排序。
- ZIP/CBZ 文件自身使用相对路径参与外部排序。
- ZIP/CBZ 内部图片使用压缩包内逻辑路径参与内部排序。
- 合并后的 Page 流应保持稳定自然顺序。

示例：

```text
BookFolder/
  Vol.01.zip
  Vol.02.zip
```

生成页面流：

```text
Vol.01.zip / page001
Vol.01.zip / page002
Vol.02.zip / page001
Vol.02.zip / page002
```

错误边界：

- 某个子 ZIP/CBZ 打不开时，MVP 可以显示错误占位页或在加载状态中提示，但不能导致整个 Book 崩溃。
- 子 ZIP/CBZ 里的非图片文件继续忽略。
- 子 ZIP/CBZ 里的嵌套压缩包继续忽略。

## 4.2 打开单张图片

当用户打开单张图片时：

1. ComicPlate 把它作为单页 Book。
2. 图片在阅读区居中显示。
3. 页面列表只有 1 页。
4. 不自动扫描同目录其他图片。

## 5. 当前阅读组和翻页

页面索引：

- 内部使用 0-based index。
- UI 显示使用 1-based：`3 / 120`。

当前阅读组：

- 阅读带是一个连续横向 slide。
- 单页模式的当前阅读组包含 1 页。
- 双页模式的当前阅读组包含 2 页；第 1 页封面可以单独成组。
- 当前阅读组在吸附动作完成后应在阅读画布中居中或作为视觉焦点。
- 左右键和底部 Left/Right 按钮移动的是当前阅读组，并触发吸附。
- 鼠标拖拽和连续滚动移动的是阅读带 offset，不应强制当前阅读组立刻居中。

吸附与自由移动：

- 翻页模式是“吸附”：打开 Book、点击页面列表、Left/Right 按钮、键盘左右键、Home/End、切换单页/双页模式时，阅读带应吸附到目标阅读组中心。
- 拖拽/滚动模式是“自由”：用户拖拽阅读带或执行连续滚动时，主状态是阅读带 offset，画面可以停在两个阅读组之间。
- 自由移动期间可以同步最近的当前页/当前阅读组，用于页码、缓存窗口和进度显示，但同步当前页不应反过来立刻重置画面位置。
- 当用户再次触发明确翻页动作时，ComicPlate 才根据当前 offset、阅读方向和单页/双页模式选择目标阅读组并吸附居中。
- 如果自由移动停在页面边界附近，当前页可取视口中心最近的页面；双页模式后续应取视口中心最近的阅读组。

单页模式：

- `NextPage`：当前索引 + 1。
- `PreviousPage`：当前索引 - 1。
- 到达第一页再上一页：停在第一页。
- 到达最后一页再下一页：停在最后一页。
- MVP 不循环翻页。

默认键位：

- 默认阅读方向为 RightToLeft。
- RightToLeft 下：`Left Arrow`：下一页，`Right Arrow`：上一页。
- LeftToRight 下：`Right Arrow`：下一页，`Left Arrow`：上一页。
- `Space`：下一页。
- `Backspace`：上一页。
- `Home`：第一页。
- `End`：最后一页。
- `O` 或平台菜单：打开。

注意：

- 左右键从一开始就应围绕阅读方向设计，避免后续翻转用户习惯。
- 如果某个技术切片临时固定左右键，必须标记为临时实现，不写入产品规则。

底部视觉翻页控制：

本次已完成：

- 底部翻页按钮使用视觉方向命名：`Left` / 当前页码 / `Right`。
- `Left` 表示向阅读区左侧移动；`Right` 表示向阅读区右侧移动。
- RightToLeft 下：`Left` 进入下一阅读组，`Right` 返回上一阅读组。
- LeftToRight 下：`Right` 进入下一阅读组，`Left` 返回上一阅读组。
- 底部按钮和键盘左右键使用同一套视觉方向规则。
- 单页模式每次移动 1 页；双页模式每次移动 1 个双页阅读组。

MVP：

- 鼠标滚轮可以先作为离散翻页输入实现，但产品目标是自由移动阅读带。
- 离散滚轮每次移动一个阅读组并吸附；自由滚轮移动 offset，不自动吸附。
- 横向阅读带按连续 slide 心智实现，允许先使用离散位置切换，不要求物理惯性或拖动预览。

底部进度条：

本次已完成：

- 进度条是显示型页码进度，不参与鼠标拖动或点击定位。
- MVP 进度条只表达当前阅读位置的大致页码进度，不作为精确导航控件。
- 进度条的深色和浅色交界点表示当前阅读组在阅读带里的大致相对位置。
- 深色区域表示当前阅读组左侧的区域；浅色区域表示当前阅读组右侧的区域。
- 进度条位置必须和阅读带方向一致。
- RightToLeft 下：第 1 页在阅读区最右侧，所以进度条初始接近全深色；继续阅读时当前位置向左移动，深色区域变短。
- LeftToRight 下：第 1 页在阅读区最左侧，所以进度条初始接近全浅色；继续阅读时当前位置向右移动，深色区域变长。
- 进度条内部仍以 0-based index 计算位置，但会根据阅读方向换算视觉位置。
- UI 页码文字继续使用 1-based：`1 / 22`。

未来状态：

- 进度条可以升级为可点击、可拖动的快速定位控件。
- 拖动进度条时应按阅读方向解释位置：RightToLeft 下右侧靠近第一页，LeftToRight 下左侧靠近第一页。
- 拖动过程中的预览、缩略图提示和读条动画属于后续体验增强。
- 双页模式下进度条如何对齐阅读组、显示跨页范围和拖动落点，交给 V1 再细化。

## 6. 双页模式

状态：MVP 第一批核心体验。单页闭环跑通后立刻实现。

规则：

- 双页模式的当前阅读组显示两个相邻页面。
- 第 1 页默认单独显示，避免封面和正文错位。
- 从第 2 页开始成对显示。
- 左到右阅读：左侧显示较小页码，右侧显示较大页码。
- 右到左阅读：右侧显示较小页码，左侧显示较大页码。
- 双页翻页一次移动 1 个双页阅读组，通常等于 2 页。
- 如果最后只剩 1 页，只显示 1 页。

阅读方向映射：

- 左到右：右键下一页，左键上一页。
- 右到左：左键下一页，右键上一页。

## 6.1 横向阅读带

阅读画布应按横向阅读带设计。

目标行为：

- 吸附状态下，当前阅读组位于阅读画布中心。
- 左右邻近页面位于同一横向页面流中，形成连续 slide 阅读感。
- MVP 可以以当前项目的三页可见状态为视觉基础，但语义上必须支持当前阅读组：单页模式聚焦 1 页，双页模式聚焦 2 页。
- 代码和界面结构不应永久绑定为“中心永远只有 1 页”的孤立图片控件。
- 阅读带加载页面必须有上限，不能一次性解码整本书。
- 切换当前页时，应释放不再需要的图片资源。
- 阅读带应使用虚拟化模型：逻辑上整本 Book 是连续页面流，实际渲染和解码只覆盖视口附近窗口。
- 阅读位置应由阅读带 offset 表示；当前页/当前阅读组可以从 offset 推导或同步，不应成为唯一控制画面位置的状态。
- 虚拟化窗口至少应覆盖当前视口、相邻阅读组和拖拽过程中可能露出的页面；窗口大小可以随性能和内存策略调整。
- Bitmap 缓存必须围绕虚拟化窗口管理，离开窗口的页面应允许释放。

默认方向：

- MVP 默认 RightToLeft，用于日漫阅读。
- RightToLeft 下，视觉上的“下一页”在当前页左侧。
- RightToLeft 下，阅读带起始位置靠右；第 1 页应出现在阅读区最右侧，后续页面向左展开。
- LeftToRight 下，视觉上的“下一页”在当前页右侧。
- LeftToRight 下，阅读带起始位置靠左；第 1 页应出现在阅读区最左侧，后续页面向右展开。

## 7. 图片适配和窗口变化

MVP 默认缩放：

- AutoFit：根据阅读区实际尺寸和图片宽高比自动选择适配方式。
- 普通竖页优先适配阅读区高度，让页面尽量接近 NeeView 的大图阅读体验。
- 横向大图或跨页图优先完整适配阅读区，避免关键内容被裁切。
- 保持原始宽高比。
- 不裁切。
- 默认允许放大和缩小；小图也要能适配阅读区，避免在 25 寸屏幕上变成小图。
- 窗口大小变化时，重新计算显示尺寸。
- 阅读区可用尺寸必须按当前窗口、侧栏、工具栏、底部进度区之后的真实剩余区域计算，不能写死屏幕尺寸。

后续可选缩放：

- 原始大小。
- 适合宽度。
- 适合高度。
- 填充窗口。

AutoFit 判定：

- 图片宽高比接近普通竖页时，使用适合高度。
- 图片明显横向时，使用完整适配窗口。
- 横向阈值可以从 `imageWidth / imageHeight >= 1.25` 起步，后续根据真实漫画素材调整。
- AutoFit 属于默认阅读策略，应进入配置文件，例如 `defaultFitMode: "AutoFit"`。

MVP 不做：

- 手势缩放。
- 鼠标拖拽移动。
- 旋转。
- 裁切白边。
- 滤镜。

## 8. 历史和进度

保存时机：

- 成功打开 Book 后写入最近打开。
- 当前页变化后，延迟保存进度。
- 应用正常关闭时保存一次。

保存内容：

- Book ID。
- 显示名称。
- 最后访问时间。
- 当前页索引。
- 总页数快照。
- 来源类型：folder 或 zip。
- 阅读方向。
- 显示模式：single 或 double。

说明：

- 历史记录不是书架。
- 最近打开只记录用户主动打开过的 Book。
- ComicPlate 不扫描最近打开路径的父目录，也不自动发现同目录其他漫画。

打开历史路径：

- 路径存在：正常打开并尝试恢复页码。
- 路径不存在：保留历史项，但点击时显示“路径不存在”，不自动删除。
- 用户可以在 V1 的最近打开列表中手动移除。

## 9. 配置

MVP 默认配置：

- 默认缩放：AutoFit。
- 默认阅读方向：RightToLeft。
- 最近打开数量：20。
- 自动恢复进度：开启。

MVP 不提供快捷键设置界面。V1 做快捷键预设或少量自定义。

配置文件：

- 使用 JSON。
- 写入用户应用数据目录。
- 读失败时使用默认配置，并备份坏文件到同目录。

## 10. UI 状态

启动状态：

- 如果没有自动恢复目标，显示空阅读面板。
- 空阅读面板显示打开按钮和最近打开。

加载状态：

- 打开大文件夹或压缩包时显示加载状态。
- 加载过程中禁用翻页。

阅读状态：

- 主区域显示横向阅读带。
- 左侧显示基础页面列表侧栏。
- 底部或顶部显示当前页码。
- 有错误页时显示错误信息。

空状态：

- 没有页面时不进入普通阅读状态。

## 11. 右键菜单范围

右键菜单按区域定义，不做用户自定义菜单。

主阅读区：

- 下一页。
- 上一页。
- 单页/双页切换。
- 适配窗口。
- 阅读方向。
- 在 Finder/Explorer 中显示当前图片或当前 Book。
- 复制当前图片路径。

目录侧栏：

- 跳转到该页。
- 在 Finder/Explorer 中显示该页。
- 复制路径。

空阅读面板/最近打开：

- 打开。
- 在 Finder/Explorer 中显示。
- 复制路径。
- 从最近打开中移除。这个操作只删除 ComicPlate 记录，不删除磁盘文件。

任何区域都不显示：

- 删除原文件。
- 移动原文件。
- 重命名原文件。
- 修改压缩包。
- 导出并覆盖原文件。

## 12. 不支持行为

MVP 明确不支持：

- RAR/7z/PDF。
- EPUB/MOBI。
- 嵌套压缩包。
- 动图播放。
- 视频。
- 插件。
- 脚本。
- 可自定义命令。
- 复杂文件管理。
- 书签。
- 可停靠/拖拽组合面板。
