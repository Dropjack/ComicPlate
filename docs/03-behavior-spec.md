# Behavior Spec

本文规定 ComicPlate 的行为边界。后续写代码时，以这里为准；如果代码和这里冲突，先改文档或先改代码，但不能心里默认。

## 0. 只读原则

ComicPlate MVP 是只读阅读器。

允许写入：

- ComicPlate 自己的设置文件。
- ComicPlate 自己的阅读进度文件。
- ComicPlate 自己的会话和阅读进度记录。
- ComicPlate 自己的日志或缓存。

禁止写入：

- 删除用户图片。
- 移动用户图片。
- 重命名用户图片。
- 修改压缩包内容。
- 覆盖原图。
- 写回元数据。

右键菜单、快捷键、侧栏和任何工具按钮都必须遵守这个原则。

## 1. Book 身份

本文中的 Book 是工程统一概念，对用户来说就是“当前正在阅读的一本漫画/一个图片范围”。Book 是可阅读 Page 序列，可以只有 1 页，也可以有多页；Book 不承担 Collection/Shelf 导航层级。

- 文件夹 = 一个可阅读单元，可以作为一本 Book 打开。
- ZIP/CBZ = 一个可阅读单元，可以作为一本 Book 打开。
- RAR/CBR = V1 可阅读单元候选；CBR 按 RAR 漫画扩展处理，RAR 只作为手动打开兼容。
- 单张图片可以作为一本 1-page Book 打开，但 ComicPlate 不是单张图片查看器，不因单图打开自动串联同目录图片。
- 单张图片 = 一个单页 Book，居中显示。
- Book 里面的图片 = Page。
- ComicPlate 不识别漫画作品，也不维护漫画库；它只解释用户显式打开或文件关联传入的路径。
- Collection = 当前正在浏览的一层可导航容器。Collection 可以包含 Book entry 和子 Collection entry。
- Shelf = Collection 在左侧 Navigation Pane 中的 UI 呈现；Shelf 本身不是书架或全局库。

- 文件夹 Book ID：规范化后的绝对路径。
- ZIP/CBZ/RAR/CBR Book ID：规范化后的绝对路径。
- Book ID 是最终打开的可阅读单元路径，不是启动入口路径。
- 同一本漫画无论从文件关联、命令行、Everything、Open Comic File、拖拽快速浏览、还是从父文件夹 Context Shelf 点入，只要最终路径相同，就命中同一条 progress 记录。
- MVP 不使用内容 hash。
- 如果同一路径的内容变化，仍视为同一本书，但打开时重新扫描页面列表。
- 如果上次记录的页码超过新页面数量，恢复到最后一页。

## 1.1 启动和打开入口

ComicPlate 有两种启动路径：

1. exe 空启动：显示轻量启动面板，让用户选择继续阅读上一次位置或打开漫画。
2. 文件关联/命令行路径启动：直接打开传入路径，跳过启动面板。

启动面板不是书架。它只包含：

- Continue Reading：打开上一次阅读位置；有可恢复会话时文案包含上次内容名，例如 `Continue Reading "BookA.cbz"`；没有可恢复会话时按钮不可用，不额外解释。
- Open Comic File：打开新的漫画文件入口。用户选择压缩包或图片文件后，ComicPlate 打开该文件，并以其所在目录建立正常 Context Shelf。
- Open Folder / Collection：打开文件夹或合集入口。用户选择文件夹后，ComicPlate 以该文件夹作为当前 Collection。
- 拖拽文件：快速浏览入口。用户拖入压缩包或图片文件后，ComicPlate 只打开该文件，不自动展示所在目录，Navigation Pane 关闭且不可用。

启动面板不显示历史列表，不显示最近打开列表，不提供上上次入口。

命令行/文件关联路径入口只接收路径并打开，不负责注册文件关联，不修改系统默认程序，不写 Windows 注册表。CLI 只是开发测试方式；资源管理器、Everything、拖到 exe、未来文件关联都会复用同一个路径参数入口。

## 1.2 Collection、Shelf 和 Book

Book 是用户主动选择打开、文件关联传入，或从 Shelf View/History View 点开的可阅读路径。ComicPlate 对它的阅读行为取决于路径类型。

Collection 是左侧可导航的一层容器。Shelf View 是当前 Collection 在 Navigation Pane 里的 UI 呈现。History View 是最近阅读 Book 列表，不产生 Collection 导航授权。

打开 Book 只改变主阅读面板、当前进度、当前高亮和定位目标；不把 Book 放进 Up 栈。进入 Collection 才改变 Shelf View 的当前层级和 NavigateUp 栈。`U` 优先沿这个栈向上，栈为空时按当前 Collection 的真实父目录继续向上一级。

同一个物理文件夹路径可以同时作为“文件夹 Book 的 Page 来源”和“Collection 的导航路径”，但这两个语义必须分开处理：作为 Book 时读取当前层图片形成 Page 流；作为 Collection 时列出当前层 Book entry 和子 Collection entry。

当用户选择一个文件夹时：

1. ComicPlate 把这个文件夹作为当前 Collection。
2. 只扫描当前文件夹一层，不全量递归。
3. 当前层支持格式图片进入主阅读/预览面板的 Page 流。
4. 当前层支持的压缩包和图片文件显示为左侧 Context Shelf entry。
5. 当前层子文件夹显示为左侧 Context Shelf entry。
6. 如果当前层只有图片且没有子文件夹/压缩包，可以直接作为文件夹漫画阅读。
7. 如果当前层没有可显示内容，显示空状态。
8. 当前 Collection 列表中的每个条目都应有缩略图或占位图。

当用户选择一个 ZIP/CBZ 时：

1. ComicPlate 把这个压缩包作为一个 Book。
2. 读取压缩包内支持格式图片。
3. 不解压到用户目录，也不修改压缩包内容。
4. 按压缩包内逻辑路径自然排序，生成线性 Page 流。

当用户选择一个包含多个卷册压缩包或多个子文件夹的文件夹时：

- MVP 不把它们串联进同一本 Book。
- MVP 在当前 Collection 列表中显示这些直接子项。
- 用户选择某个子项后再进入阅读。
- 文件夹内压缩包串联、7z/CB7 和压缩包套压缩包不属于当前 V1。
- RAR/CBR 属于当前 V1 候选：实现后与 ZIP/CBZ 一样作为单独 Book 打开，不和父文件夹内容串联。

压缩包套压缩包不进入 MVP，也不进入当前 V1：如果 ZIP/CBZ/RAR/CBR 内还有 ZIP/CBZ/RAR/CBR/7z 等压缩包，可以忽略它们或作为不可打开项处理，不能导致崩溃。

ComicPlate 不提供书架排序、过滤、分组配置。用户通过文件系统管理自己的漫画内容。

## 2. 支持图片格式

MVP 支持：

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.bmp`
- `.gif`

MVP 行为：

- 扩展名大小写不敏感。
- `.gif` 只显示第一帧，不播放动画。
- 非图片文件忽略，不提示。
- 图片扩展名正确但解码失败，显示错误占位页，并允许继续翻页。

## 3. 打开文件夹 Book

当用户打开一个文件夹时：

1. MVP 只读取当前文件夹一层。
2. 过滤支持的图片扩展名。
3. 当前层图片作为主面板 Page 流。
4. 当前层子文件夹、支持压缩包和图片文件作为左侧 Context Shelf entry。
5. 对当前层项目使用自然排序，升序。
6. 如果当前层只有图片且没有子文件夹/压缩包，可以直接进入阅读。
7. 如果当前层既有图片又有子文件夹/压缩包，图片显示在主面板，同时图片文件、子文件夹和压缩包显示在左侧 Context Shelf。
8. 如果没有可显示项，显示空状态：“这个文件夹里没有可阅读内容”。

MVP 默认：

- 不递归扫描深层目录。
- 不把深层图片提前摊平到当前列表。
- 文件夹漫画作为阅读对象时，只读取当前文件夹直接图片。

自然排序要求：

- `1.jpg, 2.jpg, 10.jpg` 的顺序应为 `1, 2, 10`。
- 排序应尽量接近系统文件管理器直觉。
- 同名不同扩展名时，按完整文件名稳定排序。

## 4. 打开 ZIP/CBZ/RAR/CBR Book

当用户打开 ZIP/CBZ/RAR/CBR Book 时：

1. 枚举压缩包内所有条目。
2. 忽略目录条目。
3. 过滤支持的图片扩展名。
4. 忽略非图片文件。
5. 默认包含压缩包内子目录中的图片。
6. 按条目完整路径自然排序。
7. 路径分隔符统一处理为 `/` 后排序。
8. 忽略压缩包内的压缩包条目，不做嵌套读取。
9. 不把压缩包解到用户目录，不修改用户压缩包。

错误边界：

- ZIP 文件打不开：显示错误状态，不崩溃。
- RAR/CBR 文件打不开：显示错误状态，不崩溃。
- ZIP/CBZ/RAR/CBR 里没有图片：显示空状态。
- 单张图片解码失败：显示错误占位页，可继续翻页。
- 密码 ZIP/RAR：当前不支持密码输入，显示“不支持加密压缩包”或等价错误状态。

## 4.1 当前 Collection 中的压缩包

当用户打开一个文件夹 Collection 时，MVP 只扫描当前层的 `.zip` 和 `.cbz`。当前 V1 加入 RAR/CBR 后，也只扫描当前层的 `.rar` 和 `.cbr`。

排序规则：

- 当前层文件系统图片按文件名自然排序。
- 当前层 ZIP/CBZ/RAR/CBR 按文件名自然排序。
- 统一列表可以按名称自然排序，也可以按类型分组后在组内自然排序；具体 UI 以 `04-ui-ux-spec.md` 为准。
- 用户打开某个 ZIP/CBZ/RAR/CBR 后，压缩包内部图片使用压缩包内逻辑路径自然排序。

示例：

```text
BookFolder/
  Vol.01.zip
  Vol.02.zip
```

当前 Collection 列表：

```text
Vol.01.zip
Vol.02.zip
```

错误边界：

- 某个 ZIP/CBZ/RAR/CBR 打不开时，显示错误状态，但不能导致整个应用崩溃。
- ZIP/CBZ/RAR/CBR 里的非图片文件继续忽略。
- ZIP/CBZ/RAR/CBR 里的嵌套压缩包不进入 MVP，也不进入当前 V1。

## 4.2 打开单张图片

当用户打开单张图片时：

1. ComicPlate 把它作为单页 Book。
2. 图片在阅读区居中显示。
3. 页面列表只有 1 页。
4. 不自动扫描同目录其他图片。

## 4.3 Context Shelf 缩略图

Context Shelf 中的缩略图规则：

- ZIP/CBZ/RAR/CBR Book entry：读取压缩包内第一张可读图片作为缩略图。
- 文件夹 Book entry 或子 Collection entry：优先使用该文件夹当前层第一张可读图片；如果没有直接图片，可以使用该文件夹当前层第一个可读子项的封面；找不到时显示文件夹占位图。
- 缩略图应保持图片比例并居中显示，不裁切关键内容。
- ZIP/CBZ 和文件夹缩略图必须叠加类型遮罩或角标，让用户能区分它是容器而不是普通图片。

性能规则：

- 缩略图必须懒加载，只为当前可见或即将可见的列表项生成。
- 缩略图缓存必须有内存上限。
- 缩略图缓存和阅读图缓存分开管理。
- 生成缩略图失败时显示类型占位图，不影响打开或阅读。
- MVP 不要求持久化磁盘缩略图缓存；如果添加磁盘缓存，必须写入 ComicPlate 自己的缓存目录，不写入用户漫画目录。

## 5. 当前阅读组和翻页

页面索引：

- 内部使用 0-based index。
- UI 显示使用 1-based：`3 / 120`。

当前阅读组：

- 阅读带是一个连续横向 slide。
- 单页模式的当前阅读组包含 1 页。
- 双页模式的当前阅读组包含 2 页；第 1 页封面可以单独成组。
- 当前阅读组在吸附动作完成后应在阅读画布中居中或作为视觉焦点。
- 左右键和底部 Left/Right 按钮移动的是当前阅读组，并触发吸附。
- `Up` / `Down` 不属于翻页语义。阅读区获得焦点时，`Up` / `Down` 仍然控制左侧 Navigation Pane 的当前选择：Shelf 模式下移动 Shelf 选择并打开对应 entry；History 模式下移动 History 选择并打开对应 Book。Reader 只跟随 Navigation Pane 的选中项自动刷新。
- 鼠标拖拽和连续滚动移动的是阅读带 offset，不应强制当前阅读组立刻居中。

吸附与自由移动：

- 翻页模式是“吸附”：打开 Book、点击页面列表、Left/Right 按钮、键盘左右键、Home/End、切换单页/双页模式时，阅读带应吸附到目标阅读组中心。
- 拖拽/滚动模式是“自由”：用户拖拽阅读带或执行连续滚动时，主状态是阅读带 offset，画面可以停在两个阅读组之间。
- 自由移动期间可以同步最近的当前页/当前阅读组，用于页码、缓存窗口和进度显示，但同步当前页不应反过来立刻重置画面位置。
- 当用户再次触发明确翻页动作时，ComicPlate 才根据当前 offset、阅读方向和单页/双页模式选择目标阅读组并吸附居中。
- 如果自由移动停在页面边界附近，当前页可取视口中心最近的页面；双页模式后续应取视口中心最近的阅读组。

单页模式：

- `NextPage`：当前索引 + 1。
- `PreviousPage`：当前索引 - 1。
- 到达第一页再上一页：停在第一页。
- 到达最后一页再下一页：停在最后一页。
- MVP 不循环翻页。

默认键位：

- 默认阅读方向为 RightToLeft。
- RightToLeft 下：`Left Arrow`：下一页，`Right Arrow`：上一页。
- LeftToRight 下：`Right Arrow`：下一页，`Left Arrow`：上一页。
- `Space`：下一页。
- `Backspace`：上一页。
- `Up` / `Down`：移动当前 Navigation Pane 选择；Shelf 模式选择 Shelf 上/下一项，History 模式选择 History 上/下一本，Reader 跟随选中项打开。
- `Home`：第一页。
- `End`：最后一页。
- `O` 或平台菜单：打开。

注意：

- 左右键从一开始就应围绕阅读方向设计，避免后续翻转用户习惯。
- 如果某个技术切片临时固定左右键，必须标记为临时实现，不写入产品规则。

底部视觉翻页控制：

本次已完成：

- 底部翻页按钮使用视觉方向命名：`Left` / 当前页码 / `Right`。
- `Left` 表示向阅读区左侧移动；`Right` 表示向阅读区右侧移动。
- RightToLeft 下：`Left` 进入下一阅读组，`Right` 返回上一阅读组。
- LeftToRight 下：`Right` 进入下一阅读组，`Left` 返回上一阅读组。
- 底部按钮和键盘左右键使用同一套视觉方向规则。
- 单页模式每次移动 1 页；双页模式每次移动 1 个双页阅读组。

MVP：

- 鼠标滚轮可以先作为离散翻页输入实现，但产品目标是自由移动阅读带。
- 离散滚轮每次移动一个阅读组并吸附；自由滚轮移动 offset，不自动吸附。
- 横向阅读带按连续 slide 心智实现，允许先使用离散位置切换，不要求物理惯性或拖动预览。

底部进度条：

本次已完成：

- 进度条是显示型页码进度，不参与鼠标拖动或点击定位。
- MVP 进度条只表达当前阅读位置的大致页码进度，不作为精确导航控件。
- 进度条的深色和浅色交界点表示当前阅读组在阅读带里的大致相对位置。
- 深色区域表示当前阅读组左侧的区域；浅色区域表示当前阅读组右侧的区域。
- 进度条位置必须和阅读带方向一致。
- RightToLeft 下：第 1 页在阅读区最右侧，所以进度条初始接近全深色；继续阅读时当前位置向左移动，深色区域变短。
- LeftToRight 下：第 1 页在阅读区最左侧，所以进度条初始接近全浅色；继续阅读时当前位置向右移动，深色区域变长。
- 进度条内部仍以 0-based index 计算位置，但会根据阅读方向换算视觉位置。
- UI 页码文字继续使用 1-based：`1 / 22`。

未来状态：

- 进度条可以升级为可点击、可拖动的快速定位控件。
- 拖动进度条时应按阅读方向解释位置：RightToLeft 下右侧靠近第一页，LeftToRight 下左侧靠近第一页。
- 拖动过程中的预览、缩略图提示和读条动画属于后续体验增强。
- 双页模式下进度条如何对齐阅读组、显示跨页范围和拖动落点，交给 V1 再细化。

## 6. 双页模式

状态：MVP 第一批核心体验。单页闭环跑通后立刻实现。

规则：

- 双页模式的当前阅读组显示两个相邻页面。
- 第 1 页默认单独显示，避免封面和正文错位。
- 从第 2 页开始成对显示。
- 左到右阅读：左侧显示较小页码，右侧显示较大页码。
- 右到左阅读：右侧显示较小页码，左侧显示较大页码。
- 双页翻页一次移动 1 个双页阅读组，通常等于 2 页。
- 如果最后只剩 1 页，只显示 1 页。

阅读方向映射：

- 左到右：右键下一页，左键上一页。
- 右到左：左键下一页，右键上一页。

## 6.1 横向阅读带

阅读画布应按横向阅读带设计。

目标行为：

- 吸附状态下，当前阅读组位于阅读画布中心。
- 左右邻近页面位于同一横向页面流中，形成连续 slide 阅读感。
- MVP 可以以当前项目的三页可见状态为视觉基础，但语义上必须支持当前阅读组：单页模式聚焦 1 页，双页模式聚焦 2 页。
- 代码和界面结构不应永久绑定为“中心永远只有 1 页”的孤立图片控件。
- 阅读带加载页面必须有上限，不能一次性解码整本书。
- 切换当前页时，应释放不再需要的图片资源。
- 阅读带应使用虚拟化模型：逻辑上整本 Book 是连续页面流，实际渲染和解码只覆盖视口附近窗口。
- 阅读位置应由阅读带 offset 表示；当前页/当前阅读组可以从 offset 推导或同步，不应成为唯一控制画面位置的状态。
- 虚拟化窗口至少应覆盖当前视口、相邻阅读组和拖拽过程中可能露出的页面；窗口大小可以随性能和内存策略调整。
- Bitmap 缓存必须围绕虚拟化窗口管理，离开窗口的页面应允许释放。

默认方向：

- MVP 默认 RightToLeft，用于日漫阅读。
- RightToLeft 下，视觉上的“下一页”在当前页左侧。
- RightToLeft 下，阅读带起始位置靠右；第 1 页应出现在阅读区最右侧，后续页面向左展开。
- LeftToRight 下，视觉上的“下一页”在当前页右侧。
- LeftToRight 下，阅读带起始位置靠左；第 1 页应出现在阅读区最左侧，后续页面向右展开。

## 7. 图片适配和窗口变化

MVP 默认缩放：

- AutoFit：根据阅读区实际尺寸和图片宽高比自动选择适配方式。
- 普通竖页优先适配阅读区高度，让页面尽量接近 NeeView 的大图阅读体验。
- 横向大图、跨页图和双页阅读组仍优先按阅读区高度适配，允许宽度超过阅读区；用户通过横向阅读带移动查看超出部分。
- 保持原始宽高比。
- 不裁切。
- 默认允许放大和缩小；小图也要能适配阅读区，避免在 25 寸屏幕上变成小图。
- 窗口大小变化时，重新计算显示尺寸。
- 阅读区可用尺寸必须按当前窗口、侧栏、工具栏、底部进度区之后的真实剩余区域计算，不能写死屏幕尺寸。

后续可选缩放：

- 原始大小。
- 适合宽度。
- 适合高度。
- 填充窗口。

AutoFit 判定：

- 图片宽高比接近普通竖页时，使用适合高度。
- AutoFit 不再按横向阈值切换到完整适配窗口；横向阈值只用于识别宽页是否参与双页配对等 frame 规则。
- AutoFit 属于默认阅读策略，应进入配置文件，例如 `defaultFitMode: "AutoFit"`。

MVP 不做：

- 手势缩放。
- 鼠标拖拽移动。
- 旋转。
- 裁切白边。
- 滤镜。

## 7.1 放大镜

放大镜用于桌面阅读时临时看清漫画小字。它不是系统全局放大镜，也不是圆形镜片；它只在 ComicPlate Reader 内部，把漫画内容层按鼠标位置作为焦点临时整体放大。

行为：

- 按住 `Z` 启用放大镜，松开 `Z` 立即关闭；`Z` 不是切换开关。
- `Z` 只在 Reader 阅读语境中生效，不是全局快捷键。
- 设置中关闭放大镜后，`Z` 完全无效，滚轮保持原有阅读行为。
- 第一次按住 `Z` 时倍率为 `1.5x`。
- 按住 `Z` 时，滚轮只调节放大倍率，不再触发阅读带移动或阅读进度变化。
- 倍率范围为 `1.5x` 到 `2.5x`，滚轮调节为连续变化。
- 倍率只在本次运行中记忆：松开 `Z` 后再次按住从上次调节的倍率开始；关闭 ComicPlate 后恢复 `1.5x`。
- 放大镜关闭时显示倍率为 `1.0x`；放大中显示当前倍率。
- 放大镜倍率不写入 settings。

边界：

- 放大以鼠标所在 Reader 内容点为焦点，产生临时 scale 和临时 offset。
- 临时 offset 不改变真实阅读带位置、不改变当前页、不写入 progress。
- 临时 offset 必须限制在当前 Reader 内容边界内，不能让 Reader Stage 露出内容外空白。
- 当鼠标继续向外移动且继续跟随会露白时，放大镜 offset 在该方向停在内容边界；另一个方向仍可继续跟随。
- 放大对象只包含 Reader 漫画内容层，不放大 Command Rail、Context Shelf、设置窗口、底部页码和进度控件。

## 8. 会话和进度

保存时机：

- 成功打开 Book 后更新全局 lastSession。
- 当前页变化后，延迟保存进度。
- 应用正常关闭时保存一次。

保存内容：

- Book ID。
- 显示名称。
- 最后访问时间。
- 当前页索引。
- 总页数快照。
- 来源类型：folder 或 zip。
- 启动来源：manual open 或 file association，可选记录。
- ReadingContainer：当前 Book 所在的可导航容器；文件夹 Book 自身可以是它的 reading container。
- ReadingParentCollection：能在 Shelf View 里高亮当前 Book 的父 Collection，是 Locate 和 Continue Reading 恢复 Shelf 的主依据。
- 阅读方向。
- 显示模式：single 或 double。

说明：

- lastSession 只有一个，用于启动面板的 Continue Reading。
- 多窗口同时存在时，最后更新或最后关闭的窗口写入 lastSession；MVP 使用最后写入胜出。
- 每本 Book 可以保存一个 progress 记录，用于用户再次从资源管理器、Everything、CLI 或 Open Comics 打开同一路径时恢复页码。
- progress 查找发生在最终 Book 打开时，而不是在启动入口或父容器打开时；例如先从 `A.cbz` 启动读到第 100 页，下次打开 `manga` 文件夹再从 shelf 点进 `A.cbz`，仍应恢复到第 100 页。
- History View 可以从 lastSession/progress 派生最近阅读 Book 列表，当前显示上限为 25 条；它不是书架，不扫描目录，也不改变 Collection 导航栈。
- progress 记录必须有硬上限，例如 500 条；超过上限按最后访问时间删除最旧记录。
- 如果关闭时停在最后一页，MVP 可以删除该 Book 的 progress 记录，视为已读完；后续优化时再评估完成状态是否更温和。
- ComicPlate 不扫描 progress 路径的父目录，也不自动发现同目录其他漫画。

打开已记录进度的路径：

- 路径存在：正常打开并尝试恢复页码。
- 路径不存在：打开失败时提示，不启动全量清理。
- 路径内容变化导致页码越界：夹到最后一页或回到第一页，具体实现以最不打断阅读为准。

## 9. 配置

MVP 默认配置：

- 默认缩放：AutoFit。
- 默认阅读方向：RightToLeft。
- 进度记录上限：500。
- 自动恢复进度：开启。

MVP 不提供快捷键设置界面。V1 做快捷键预设或少量自定义。

配置文件：

- 使用 JSON。
- 写入用户应用数据目录。
- 读失败时使用默认配置，并备份坏文件到同目录。

## 10. UI 状态

启动状态：

- exe 空启动时显示轻量启动面板。
- 启动面板显示 Continue Reading 和 Open Comics。
- 如果由文件关联或命令行传入路径启动，直接打开传入路径。

加载状态：

- 打开大文件夹或压缩包时显示加载状态。
- 加载过程中禁用翻页。

阅读状态：

- 主区域显示横向阅读带。
- 左侧显示 Navigation Pane；Shelf View 只包含当前 Collection 的一层可打开项，History View 只包含最近阅读 Book。
- 底部或顶部显示当前页码。
- 有错误页时显示错误信息。

空状态：

- 没有页面时不进入普通阅读状态。

## 11. 右键菜单范围

右键菜单按区域定义，不做用户自定义菜单。

主阅读区：

- 下一页。
- 上一页。
- 单页/双页切换。
- 适配窗口。
- 阅读方向。
- 在 Finder/Explorer 中显示当前图片或当前 Book。
- 复制当前图片路径。

Context Shelf：

- 打开。
- 在 Finder/Explorer 中显示。
- 复制路径。

启动面板：

- Continue Reading。
- Open Comic File。
- Open Folder / Collection。
- 拖拽文件快速浏览。

任何区域都不显示：

- 删除原文件。
- 移动原文件。
- 重命名原文件。
- 修改压缩包。
- 导出并覆盖原文件。

## 12. 不支持行为

MVP 明确不支持：

- 7z/CB7/PDF。
- EPUB/MOBI。
- 嵌套压缩包。
- 自动文件关联；V1 只允许用户在设置中显式关联已支持格式。
- 动图播放。
- 视频。
- 插件。
- 脚本。
- 可自定义命令。
- 复杂文件管理。
- 书签。
- 可停靠/拖拽组合面板。
