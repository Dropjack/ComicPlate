# Behavior Spec

本文规定 ComicPlate 的行为边界。后续写代码时，以这里为准；如果代码和这里冲突，先改文档或先改代码，但不能心里默认。

## 0. 只读原则

ComicPlate MVP 是只读阅读器。

允许写入：

- ComicPlate 自己的设置文件。
- ComicPlate 自己的阅读进度文件。
- ComicPlate 自己的最近打开记录。
- ComicPlate 自己的日志或缓存。

禁止写入：

- 删除用户图片。
- 移动用户图片。
- 重命名用户图片。
- 修改压缩包内容。
- 覆盖原图。
- 写回元数据。

右键菜单、快捷键、侧栏和任何工具按钮都必须遵守这个原则。

## 1. Book 身份

本文中的 Book 是工程统一概念，对用户来说就是“一本漫画书”。

- 文件夹漫画 = 一本 Book。
- ZIP/CBZ 漫画 = 一本 Book。
- Book 里面的图片 = Page。
- 书架显示很多 Book。

- 文件夹 Book ID：规范化后的绝对路径。
- ZIP/CBZ Book ID：规范化后的绝对路径。
- 书架根目录 ID：规范化后的绝对路径。
- MVP 不使用内容 hash。
- 如果同一路径的内容变化，仍视为同一本书，但打开时重新扫描页面列表。
- 如果上次记录的页码超过新页面数量，恢复到最后一页。

## 1.1 书架

书架是 Book 的列表，不是 Page 的列表。

当用户选择一个书架根目录时：

1. ComicPlate 从书架根目录开始递归扫描文件系统目录。
2. 扫描过程中遇到 `.zip` 或 `.cbz` 文件时，将它识别为一本 ZIP/CBZ Book。
3. 扫描过程中遇到“直接包含支持格式图片”的文件夹时，将它识别为一本文件夹 Book。
4. 某个文件夹已经被识别为 Book 后，书架扫描不再把它的子文件夹重复列为独立 Book；这些子文件夹属于该 Book 内部的章节结构。
5. 如果某个文件夹本身不直接包含图片，但它下面还有子文件夹或 ZIP/CBZ，继续向下扫描。
6. 书架默认按名称自然排序；同名时按完整路径稳定排序。
7. 书架不修改、移动、删除、重命名任何源文件或源文件夹。

打开书架中的文件夹 Book 后，Book 内部可以递归读取章节目录中的图片。

打开书架中的 ZIP/CBZ Book 后，ComicPlate 读取压缩包内图片，但不解压到用户目录，也不修改压缩包内容。

压缩包套压缩包不支持：如果 ZIP/CBZ 内还有 ZIP/CBZ/RAR/7z 等压缩包，MVP 直接忽略，不把它们当作页面或子书籍。

书架扫描和 Page 收集是两件事：

- 书架扫描负责发现“哪些东西是 Book”。
- Page 收集负责打开一本 Book 后，找出这本 Book 里的图片页面。
- 书架扫描可以递归穿过普通文件夹寻找 Book，但不能进入 ZIP/CBZ 内部继续寻找子 Book。
- ZIP/CBZ 内部的子目录只属于这本 ZIP/CBZ Book 的 Page 结构。

书架排序、过滤、分组等配置需要预留配置结构，但 MVP 可以先只实现默认名称排序。

## 2. 支持图片格式

MVP 支持：

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.bmp`
- `.gif`

MVP 行为：

- 扩展名大小写不敏感。
- `.gif` 只显示第一帧，不播放动画。
- 非图片文件忽略，不提示。
- 图片扩展名正确但解码失败，显示错误占位页，并允许继续翻页。

## 3. 打开文件夹 Book

当用户打开一个文件夹 Book 时：

1. MVP 默认递归读取当前文件夹及所有子文件夹内的文件。
2. 后续可以提供“不递归”选项或书架配置，但这不是当前目标。
3. 过滤支持的图片扩展名。
4. 不把子文件夹显示为页面。
5. 对结果使用自然排序，升序。
6. 如果没有图片，显示空状态：“这个文件夹里没有可阅读的图片”。

MVP 默认：

- 默认递归扫描 Book 内部章节目录。
- 按相对路径自然排序，例如 `Chapter 1/001.jpg` 早于 `Chapter 2/001.jpg`。

自然排序要求：

- `1.jpg, 2.jpg, 10.jpg` 的顺序应为 `1, 2, 10`。
- 排序应尽量接近系统文件管理器直觉。
- 同名不同扩展名时，按完整文件名稳定排序。

## 4. 打开 ZIP/CBZ Book

当用户打开 ZIP/CBZ Book 时：

1. 枚举压缩包内所有条目。
2. 忽略目录条目。
3. 过滤支持的图片扩展名。
4. 忽略非图片文件。
5. 默认包含压缩包内子目录中的图片。
6. 按条目完整路径自然排序。
7. 路径分隔符统一处理为 `/` 后排序。
8. 忽略压缩包内的压缩包条目，不做嵌套读取。

错误边界：

- ZIP 文件打不开：显示错误状态，不崩溃。
- ZIP 里没有图片：显示空状态。
- 单张图片解码失败：显示错误占位页，可继续翻页。
- 密码 ZIP：MVP 不支持，显示“不支持加密压缩包”。

## 5. 当前页和翻页

页面索引：

- 内部使用 0-based index。
- UI 显示使用 1-based：`3 / 120`。

单页模式：

- `NextPage`：当前索引 + 1。
- `PreviousPage`：当前索引 - 1。
- 到达第一页再上一页：停在第一页。
- 到达最后一页再下一页：停在最后一页。
- MVP 不循环翻页。

默认键位：

- 默认阅读方向为 RightToLeft。
- RightToLeft 下：`Left Arrow`：下一页，`Right Arrow`：上一页。
- LeftToRight 下：`Right Arrow`：下一页，`Left Arrow`：上一页。
- `Space`：下一页。
- `Backspace`：上一页。
- `Home`：第一页。
- `End`：最后一页。
- `O` 或平台菜单：打开。

注意：

- 左右键从一开始就应围绕阅读方向设计，避免后续翻转用户习惯。
- 如果某个技术切片临时固定左右键，必须标记为临时实现，不写入产品规则。

## 6. 双页模式

状态：MVP 第一批核心体验。单页闭环跑通后立刻实现。

规则：

- 双页模式显示两个相邻页面。
- 第 1 页默认单独显示，避免封面和正文错位。
- 从第 2 页开始成对显示。
- 左到右阅读：左侧显示较小页码，右侧显示较大页码。
- 右到左阅读：右侧显示较小页码，左侧显示较大页码。
- 双页翻页一次移动 2 页。
- 如果最后只剩 1 页，只显示 1 页。

阅读方向映射：

- 左到右：右键下一页，左键上一页。
- 右到左：左键下一页，右键上一页。

## 6.1 横向阅读带

阅读画布应按横向阅读带设计。

目标行为：

- 当前页位于阅读画布中心。
- 前后页位于同一横向页面流中，形成连续阅读感。
- MVP 可以先实现单页为主的居中阅读，但代码和界面结构不应永久绑定为单个孤立图片控件。
- 阅读带加载页面必须有上限，不能一次性解码整本书。
- 切换当前页时，应释放不再需要的图片资源。

默认方向：

- MVP 默认 RightToLeft，用于日漫阅读。
- RightToLeft 下，视觉上的“下一页”在当前页左侧。
- LeftToRight 下，视觉上的“下一页”在当前页右侧。

## 7. 图片适配和窗口变化

MVP 默认缩放：

- Fit：完整图片适配窗口。
- 保持原始宽高比。
- 不裁切。
- 不放大超过窗口边界。
- 窗口大小变化时，重新计算显示尺寸。

后续可选缩放：

- 原始大小。
- 适合宽度。
- 适合高度。
- 填充窗口。

MVP 不做：

- 手势缩放。
- 鼠标拖拽移动。
- 旋转。
- 裁切白边。
- 滤镜。

## 8. 历史和进度

保存时机：

- 成功打开 Book 后写入最近打开。
- 当前页变化后，延迟保存进度。
- 应用正常关闭时保存一次。

保存内容：

- Book ID。
- 显示名称。
- 最后访问时间。
- 当前页索引。
- 总页数快照。
- 来源类型：folder 或 zip。
- 阅读方向。
- 显示模式：single 或 double。

打开历史路径：

- 路径存在：正常打开并尝试恢复页码。
- 路径不存在：保留历史项，但点击时显示“路径不存在”，不自动删除。
- 用户可以在 V1 的最近打开列表中手动移除。

## 9. 配置

MVP 默认配置：

- 默认缩放：Fit。
- 默认阅读方向：RightToLeft。
- 最近打开数量：20。
- 自动恢复进度：开启。

配置文件：

- 使用 JSON。
- 写入用户应用数据目录。
- 读失败时使用默认配置，并备份坏文件到同目录。

## 10. UI 状态

启动状态：

- 如果没有自动恢复目标，显示启动页。
- 启动页显示打开按钮和最近打开。

加载状态：

- 打开大文件夹或压缩包时显示加载状态。
- 加载过程中禁用翻页。

阅读状态：

- 主区域显示横向阅读带。
- 左侧显示书架侧栏和基础页面列表侧栏。
- 底部或顶部显示当前页码。
- 有错误页时显示错误信息。

空状态：

- 没有页面时不进入普通阅读状态。

## 11. 右键菜单范围

右键菜单按区域定义，不做用户自定义菜单。

主阅读区：

- 下一页。
- 上一页。
- 单页/双页切换。
- 适配窗口。
- 阅读方向。
- 在 Finder/Explorer 中显示当前图片或当前 Book。
- 复制当前图片路径。

目录侧栏：

- 跳转到该页。
- 在 Finder/Explorer 中显示该页。
- 复制路径。

启动页/最近打开：

- 打开。
- 在 Finder/Explorer 中显示。
- 复制路径。
- 从最近打开中移除。这个操作只删除 ComicPlate 记录，不删除磁盘文件。

任何区域都不显示：

- 删除原文件。
- 移动原文件。
- 重命名原文件。
- 修改压缩包。
- 导出并覆盖原文件。

## 12. 不支持行为

MVP 明确不支持：

- RAR/7z/PDF。
- 嵌套压缩包。
- 动图播放。
- 视频。
- 插件。
- 脚本。
- 可自定义命令。
- 复杂文件管理。
- 书签。
- 可停靠/拖拽组合面板。
