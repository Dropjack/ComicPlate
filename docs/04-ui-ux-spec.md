# UI UX Spec

本文先定义信息结构和操作结构，再谈视觉风格。第一版目标是“只读、完成度够、简单漂亮、能舒服读”，不是做一个视觉演示。

## 1. 主窗口结构

主窗口有两种主要状态：

- 启动页。
- 阅读页。

阅读页基础布局：

- 左侧：目录侧栏。
- 中央：阅读画布。
- 顶部：轻量工具栏。
- 底部：页码/进度区。

不做：

- 多窗口。
- 可停靠面板。
- 拖拽组合面板。
- 复杂书架。

## 2. 启动页

启动页显示：

- 应用名 ComicPlate。
- `Open Folder` 按钮。
- `Open Comic Archive` 按钮。
- 最近打开列表。

最近打开列表每项显示：

- 书名：文件夹名或压缩包文件名。
- 路径，弱化显示。
- 上次阅读页码，如 `42 / 180`。
- 最后打开时间。

空最近列表：

- 显示简短空状态，不写长说明。

## 3. 阅读页

阅读页区域：

- 左侧：基础目录侧栏。
- 中央：图片显示区域。
- 顶部：轻量工具栏。
- 底部：页码/进度条。

目录侧栏 MVP 项：

- 当前 Book 的页面列表。
- 页码。
- 文件名或简化文件名。
- 当前页高亮。
- 点击某页跳转。

目录侧栏暂不做：

- metadata 编辑。
- 复杂信息面板。
- 可拖拽停靠。
- 用户自定义面板布局。
- 缩略图。缩略图可在后续版本加入。

顶部工具栏 MVP 项：

- 返回启动页。
- 打开。
- 文件名或书名。
- 适配模式显示。

底部 MVP 项：

- 当前页码：`12 / 96`。
- 简单进度条。

工具栏显示策略：

- MVP 可常驻，降低实现风险。
- V1 再做鼠标静止后自动隐藏。

## 4. 全屏模式

状态：V1。

行为：

- 全屏后默认隐藏工具栏。
- 鼠标移动到顶部显示工具栏。
- 鼠标移动到底部显示页码和进度条。
- `Esc` 退出全屏。

## 5. 右键菜单

状态：MVP 必须有约束，具体菜单项可随 UI 实现逐步补齐。

主阅读区：

- Next Page。
- Previous Page。
- Single Page / Double Page。
- Fit to Window。
- Reading Direction。
- Reveal in Finder/Explorer。
- Copy Current File Path。

目录侧栏：

- Jump to Page。
- Reveal in Finder/Explorer。
- Copy Path。

最近打开列表：

- Open。
- Reveal in Finder/Explorer。
- Copy Path。
- Remove from Recent。

不做：

- 可编辑右键菜单。
- 命令参数。
- 脚本命令。
- 删除、移动、重命名、修改原文件。

## 6. 设置页

状态：V1。

设置页分组：

- Reading：阅读方向、单页/双页、封面单独显示。
- Display：适配窗口、背景色、图片插值质量。
- Library：是否自动恢复进度、最近打开数量。
- Shortcuts：只展示固定快捷键，先不允许编辑。

MVP 不做设置页，但内部配置结构要能支持这些未来项。

## 7. 快捷键

跨平台通用：

- `Right Arrow`：下一页。
- `Left Arrow`：上一页。
- `Space`：下一页。
- `Backspace`：上一页。
- `Home`：第一页。
- `End`：最后一页。
- `F11`：全屏，Windows 优先。
- `Esc`：退出全屏或返回普通状态。

macOS 差异：

- 打开：`Cmd+O`。
- 设置：`Cmd+,`。
- 退出：系统默认 `Cmd+Q`。

Windows 差异：

- 打开：`Ctrl+O`。
- 设置：`Ctrl+,`。
- 全屏：`F11`。

## 8. 视觉风格

第一版原则：

- 背景克制，优先服务图片。
- 阅读页不要有装饰性卡片。
- 控件小而清楚。
- 深色模式优先，因为漫画阅读常用。
- 跟随系统浅色/深色。
- macOS 按 macOS 26 风格方向。
- Windows 按 Windows 11 风格方向。

macOS：

- 接近 macOS 原生应用的轻量感。
- 使用系统菜单习惯。
- 不在第一版追求复杂透明材质，但视觉方向参考 macOS 26。

Windows：

- 接近 Win11 的简洁工具应用。
- 不在第一版追求 Mica。

## 9. 体验基准

每次 UI 改动后检查：

- 1200x800 是否能舒服阅读。
- 800x600 是否不遮挡主要内容。
- macOS 和 Windows 快捷键文案是否正确。
- 图片区域是否永远是视觉主角。
- 工具栏和页码是否不会遮住图片关键区域。
