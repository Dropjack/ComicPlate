# Scope Cut

本文是 ComicPlate 的范围刹车。任何功能进入开发前，先看这里。

标签说明：

- MVP 必须有：没有它就不是可用的轻量漫画阅读器。
- V1 可以有：MVP 稳定后再加。
- 以后再说：现在不设计，不为它预留复杂架构。
- 永久不做：至少第一年不碰，除非项目目标重写。

| 功能 | 标签 | 原因 |
| --- | --- | --- |
| 打开文件夹作为一本书 | MVP 必须有 | 最小闭环入口 |
| 显示第一张图片 | MVP 必须有 | 垂直切片核心 |
| 左右键翻页 | MVP 必须有 | 阅读器基本操作 |
| 单页适配窗口 | MVP 必须有 | 保证打开就能看 |
| 自然排序 | MVP 必须有 | 漫画文件名常含数字 |
| 空文件夹提示 | MVP 必须有 | 必须有清楚失败状态 |
| 损坏图片提示并可跳过 | MVP 必须有 | 真实素材会出错 |
| 记住当前页 | MVP 必须有 | 阅读体验关键 |
| 最近打开列表 | MVP 必须有 | 个人阅读器必需 |
| 双页模式 | V1 可以有 | 很重要，但不挡第一个闭环 |
| 日漫/欧美阅读方向切换 | V1 可以有 | 双页前可先固定默认 |
| 全屏模式 | V1 可以有 | 体验增强 |
| 鼠标滚轮翻页 | V1 可以有 | 低成本增强 |

## MVP 的真实定义

MVP 不是“功能看起来很多”。ComicPlate 的 MVP 是：

1. 启动应用。
2. 选择一个图片文件夹。
3. 程序扫描并自然排序图片。
4. 显示第一张图。
5. 左右键翻页。
6. 关闭后再次打开同一路径，可以恢复上次页。
7. 可以打开 ZIP/CBZ 并以同样方式阅读。

MVP 不包含：

- 双页。
- 设置窗口。
- 主题。
- 插件。
- 脚本。
- 面板。
- 文件管理。
- 导出。
