# Scope Cut

本文是 ComicPlate 的范围刹车。任何功能进入开发前，先看这里。

`02` 只决定做不做、先不先做。具体行为写入 `03-behavior-spec.md`，界面结构和交互文案写入 `04-ui-ux-spec.md`。

标签说明：

- MVP 必须有：没有它就不是可用的轻量漫画阅读器。
- V1 可以有：MVP 稳定后再加。
- 以后再说：现在不设计，不为它预留复杂架构。
- 永久不做：至少第一年不碰，除非项目目标重写。

## 产品方向

ComicPlate 的最新方向：

- 为本地漫画内容设计的跨平台漫画预览器/阅读窗口。
- 少设置，专注连续阅读。
- 记住用户读到哪，但不替用户管理藏书。
- 不识别“漫画作品”，只识别“可阅读单元”。
- 优先服务文件关联和临时打开：用户从 Everything、资源管理器或系统默认程序启动时，应尽快进入阅读。
- 空启动时只提供轻量启动面板：继续阅读上一次位置、打开漫画文件、打开文件夹/合集，并提示可拖拽文件快速浏览。
- 用户打开一个容器时，ComicPlate 只展示当前容器的一层内容，不做全库递归扫描，不把目录树摊平成书架。
- 当前容器可以同时包含可打开项和当前层图片：文件夹、压缩包和图片文件进入左侧 Context Shelf，当前层图片也可作为当前文件夹的直接阅读内容进入主阅读/预览面板。
- 拖拽文件进入窗口是快速独立浏览入口：只打开被拖入的文件，不自动建立父目录 Context Shelf，Navigation Pane 应关闭且不可用。
- 阅读交互分为两类：翻页模式是“吸附”，拖拽/滚动模式是“自由”。按钮、快捷键等明确翻页动作应回到单页/双页阅读组中心；拖拽和连续滚动应移动阅读画布本身，不应每次自动拉回当前页中心。

因此，ComicPlate 不做漫画库管理器。它可以打开一个文件夹、一个单行本压缩包、一个图片文件，或由文件关联直接启动；但它不自动判断哪些内容属于同一部作品，也不维护传统 Bookshelf。文件夹漫画是 ComicPlate 的一等入口，但文件夹只是当前容器，不是全局藏书根。

## 阅读核心

| 功能 | 标签 | 原因 |
| --- | --- | --- |
| 文件夹作为可阅读单元打开 | MVP 必须有 | 常见漫画来源，也是最小闭环入口 |
| ZIP/CBZ 作为可阅读单元打开 | MVP 必须有 | 常见漫画来源，必须进入第一版完整闭环 |
| 显示第一张图片 | MVP 必须有 | 垂直切片核心 |
| 左右键翻页 | MVP 必须有 | 阅读器基本操作 |
| 单页适配窗口 | MVP 必须有 | 保证打开就能看 |
| 自然排序 | MVP 必须有 | 漫画文件名常含数字 |
| 空文件夹/空压缩包提示 | MVP 必须有 | 必须有清楚失败状态 |
| 损坏图片提示并可跳过 | MVP 必须有 | 真实素材会出错 |
| 记住当前页 | MVP 必须有 | 阅读体验关键 |
| 打开上一次阅读位置 | MVP 必须有 | exe 空启动时不进入书架，而是给用户明确入口 |
| 单张图片居中显示 | MVP 必须有 | 没有书架后，单图打开可以作为轻量预览入口 |
| 双页模式 | MVP 必须有 | 用户主要阅读习惯，也是 NeeView 核心舒适感之一 |
| 日漫/欧美阅读方向切换 | MVP 必须有 | 双页显示和左右键映射都依赖它 |
| 当前容器 Context Shelf | MVP 必须有 | 左侧只显示当前层可打开项，用来换书和回退，不承担 Page 导航 |
| Context Shelf 缩略图 | MVP 必须有 | 文件夹和压缩包在侧栏中需要一眼区分 |
| 横向连续阅读带 | MVP 必须有 | 阅读画布应呈现连续页面流，当前阅读组居中，接近 NeeView 阅读心智 |
| 鼠标滚轮翻页 | MVP 必须有 | 低成本且符合阅读器常用操作 |
| 虚拟化阅读带 | MVP 必须有 | 逻辑上支持整本书连续页面流，实际只加载视口附近页面，避免一次性解码整本漫画 |
| 全屏模式 | V1 可以有 | 体验增强，不阻塞第一版阅读闭环 |
| 鼠标拖拽自由移动阅读带 | MVP 必须有 | NeeView 式连续阅读手感的核心；拖拽移动画布，不等同于离散翻页 |
| 放大镜 | V1 可以有 | 桌面阅读小字时需要；按住 Z 临时放大 Reader 漫画内容，不进入 Command Rail |
| 书签 | 永久不做 | 自动恢复上次页已覆盖个人需求 |
| 播放列表 | 永久不做 | 偏 NeeView 高级功能 |

说明：

- 单页阅读可以作为最初技术切片先跑通，但双页必须进入 MVP 第一批核心体验。
- Context Shelf 显示当前层的可打开项。工程上可以暂用 Book 名称，但产品上不把 Book 解释成藏书库条目。
- Shelf entry 是用户可以打开阅读或进入的文件夹、压缩包或后续支持的容器；当前层图片不进入左侧 shelf，而进入主面板。
- Context Shelf 缩略图必须懒加载、有缓存上限。压缩包显示第一张可读图片；文件夹显示当前层第一张可读图片或第一项封面，并叠加类型遮罩。
- MVP 的阅读画布不应只是单个孤立图片控件；应按横向连续阅读带设计，当前阅读组居中，左右邻近页面在同一横向流中显示或预备显示。
- 单页模式的当前阅读组是 1 页，双页模式的当前阅读组是 2 页。翻页、按钮和滚轮移动的是阅读组，不是简单替换中心图片。
- “当前阅读组居中”只适用于吸附动作：打开、跳页、Left/Right、快捷键、切换单页/双页模式。拖拽和连续滚动期间，阅读带应保持自由 offset，不自动居中。
- 虚拟化是 MVP 阅读带的架构目标：Book/Page 业务层只提供线性 Page 流；阅读视图层维护阅读带 offset、可见窗口、图片缓存和释放策略。
- MVP 默认只做 Fit 适配窗口：完整显示图片、保持比例、不裁切。
- 拉伸、旋转、自由缩放、滤镜、裁切白边都不进入 MVP。

| 功能 | 标签 | 原因 |

| 文件夹图片扫描 | MVP 必须有 | 核心输入 |
| 支持 jpg/jpeg/png/webp/bmp | MVP 必须有 | 常见漫画/图片格式 |

| RAR/CBR | V1 可以有 | 漫画常见格式；CBR 是漫画向扩展，RAR 可作为手动打开兼容 |
| 7z/CB7 | 以后再说 | 当前 V1 不计划支持，除非后续真实需求或贡献证明值得引入复杂度 |
| 嵌套压缩包 | 以后再说 | 当前 V1 不计划支持；会引入临时解包、深度限制和进度身份复杂度 |
| PDF | 永久不做 | 会改变产品范围 |
| EPUB/MOBI | 永久不做 | 电子书阅读不是 ComicPlate |
| 视频/音频 | 永久不做 | 不是 ComicPlate |
| Susie 插件 | 永久不做 | Windows 特化且复杂 |

说明：

- ComicPlate 的输入范围就是图片文件夹和漫画压缩包。
- `Open` 是打开一个当前容器或一个可阅读文件，不是选择书架根目录。
- 文件夹可以是当前容器，也可以在只含当前层图片时直接作为一本文件夹漫画阅读。
- ZIP/CBZ 可以直接作为一本 Book 打开。
- 当前容器默认只扫描一层：当前层图片进入主面板 Page 流，当前层文件夹和支持压缩包成为左侧 Shelf entry。
- 打开某个 ZIP/CBZ 后，读取压缩包内图片，并按压缩包内逻辑路径自然排序。
- ZIP/CBZ 内部可以有子目录图片。压缩包套压缩包不进入 MVP，也不进入当前 V1。
- 当前 V1 压缩包范围收束为 ZIP/CBZ + RAR/CBR；不做 7z/CB7，不做嵌套压缩包。
- 非图片文件默认忽略，不作为页面，也不提示。
- 扫描要守住边界：MVP 不全量递归，不把子文件夹深处的页面提前摊平到当前列表。
- 压缩包读取不写回用户文件，也不把内容解压到用户目录。

说明：

- 启动面板必须有明确 Continue Reading、Open Comic File、Open Folder / Collection 入口；不显示最近打开列表。
- 阅读页的视觉主角永远是图片，不做装饰性卡片和复杂面板。
- 左侧栏至少包含当前容器的一层 Context Shelf；显示当前层文件夹、压缩包和图片文件，不做书架、信息、书签、播放列表、metadata 编辑等高级侧栏。
- Context Shelf 缩略图是 MVP，但必须采用懒加载和有上限缓存；不能为了缩略图一次性解码整个容器。
- 右键菜单必须遵守只读原则：不删除、移动、重命名、修改用户文件。
- 当前阶段不做右键 action 菜单；Reveal in Explorer 等对象操作保留设计口子，后续再决定入口。
- 不把 Shelf 顶部做成文件管理器工具栏。
- Context Shelf 视图样式切换可以后续评估，但不应引入搜索、排序、快速访问或完整目录浏览语义。
- 具体布局、菜单项和快捷键文案在 `04-ui-ux-spec.md` 收束。

| 功能 | 标签 | 原因 |
| --- | --- | --- |
| Avalonia 跨平台项目 | MVP 必须有 | macOS/Windows 双版本基础 |
| Book/Page 模型 | MVP 必须有 | 保留 NeeView 最舒服的核心隐喻 |

| 轻量本地化服务 | V1 可以有 | 语义 key、英文源语言、缺 key 回退英文、系统语言不支持回退英文 |
| 内置主题服务 | V1 可以有 | 少量预设主题和色彩 token，不暴露自由编辑 |
| 基础日志 | V1 可以有 | 调试打包后问题 |
| 自动更新 | 永久不做 | 个人工具不需要 |
| 插件化架构 | 永久不做 | 会拖慢 MVP |
| 复杂命令系统 | 永久不做 | 当前阶段不是目标 |
| 主题编辑器 | 永久不做 | 高成本低必要 |

说明：

- Book ID 使用规范化绝对路径即可，MVP 不做内容 hash。
- Book ID 指用户实际阅读对象的路径。文件夹漫画、单个压缩包、单图范围都按各自路径保存进度。
- 每本书进度以最终打开的可阅读单元规范化路径为 key，不以启动入口、父容器或用户从哪一级 shelf 点进来为 key。
- 如果路径变化，ComicPlate 可以把它当作一本新书，从头开始读。
- 所有写入只发生在 ComicPlate 自己的配置、进度、会话、日志或缓存中。

## MVP 的真实定义

MVP 不是“功能看起来很多”。ComicPlate 的 MVP 是：

1. 启动应用。
2. 空启动时选择继续上一次内容、打开漫画文件或打开文件夹/合集；文件关联启动时直接打开传入文件。
3. 选择一个文件夹、图片文件或 ZIP/CBZ。
4. 如果打开的是文件夹，ComicPlate 只扫描当前层：图片进入主面板，文件夹/压缩包/图片文件进入 Context Shelf；如果当前层只有图片，也可以直接作为文件夹漫画阅读。
5. 如果打开的是 ZIP/CBZ，读取压缩包内图片并自然排序。
6. 单张图片可以居中显示。
7. 阅读画布以横向连续阅读带显示页面，当前阅读组居中，左右邻近页面参与同一横向流。
8. Left/Right 按钮、左右键和鼠标滚轮移动当前阅读组。
9. 支持单页、双页和阅读方向，默认阅读方向偏向日漫右到左。
10. 有当前容器 Context Shelf 侧栏。
11. 能显示空状态和损坏图片占位，不崩溃。
12. 关闭后再次打开同一路径，可以恢复上次页。
13. 空启动时可以通过 Continue Reading 回到最后一次阅读会话。

MVP 不包含：

- 设置窗口。
- 快捷键设置。
- 语言运行时热切换。
- 可交互进度条。
- 主题编辑器。
- 插件。
- 脚本。
- 全屏。
- 复杂可停靠/拖拽组合面板。
- 底部缩略图。
- 书签。
- 文件管理。不承担删除、移动、重命名等管理能力。
- 文件关联设置面板。
- 系统右键菜单注册设置。
- RAR/CBR、7z/CB7 和嵌套压缩包。
- 导出。
- PDF/EPUB/MOBI/视频/音频阅读。

## V1 实际完成补记（2026-05-20）

以下能力原本不属于 MVP，但已经在 Phase 6/Phase 6.5 中进入当前产品事实。后续维护时不要再按“未开始”理解：

- 设置窗口已经实现，采用左侧快速链接 + 右侧单页内容结构。
- 设置项已经覆盖启动与窗口、外观、语言、阅读、数据与缓存、文件关联、系统右键菜单、快捷键入口。
- 预设配色方案已经实现：Mist Green、Slate Blue、Warm Paper、Night Graphite。它们是内置主题，不是主题编辑器。
- 主题和语言变更都是重启生效，不做运行时热切换。
- UI 本地化基础已经实现：`en`、`zh-Hans`、`ja`，默认 `system`，系统语言不支持时回退 `en`，单 key 缺失时回退 `en`。
- `en.json` 是 source of truth；本地化 key 使用语义路径，不使用英文句子当 key。
- 主要 UI 文案、tooltip、设置页、快捷键窗口、Shelf badge、Reader 状态、文件关联/右键菜单状态消息已经迁移到本地化 key。

## 启动恢复与轻量上下文

MVP 必须保存“上次阅读点”和“轻量导航上下文”，但不能把它发展成书架。

规则：

- 空启动时显示启动面板，不自动扫描任何目录。
- Continue Reading 只恢复上次正在阅读的内容、页码和一小段上层路径栈。
- 恢复时只根据保存的路径打开当前内容，不预扫描上层目录，不恢复缩略图缓存，不恢复完整 Context Shelf 扫描结果。
- Back 时才按保存的上层路径重新加载上一层容器的一层内容。
- 导航上下文最多保存少量层级，例如 8 层；它是本次阅读流的路径碎片，不是长期书架。
- 每本书可以保存上次阅读页码，但不展示为历史列表；进度记录必须有数量上限，例如 500 条。
- 如果一本书在最后一页关闭，MVP 可以删除该书的进度记录，后续再根据真实使用调整完成状态策略。

这样 ComicPlate 可以支持“继续读到第 208 页，读完后 Back 回系列目录点下一本”，但启动时仍然保持轻量、悬空，不拥有用户的漫画库。
