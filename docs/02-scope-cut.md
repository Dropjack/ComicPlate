# Scope Cut

本文是 ComicPlate 的范围刹车。任何功能进入开发前，先看这里。

标签说明：

- MVP 必须有：没有它就不是可用的轻量漫画阅读器。
- V1 可以有：MVP 稳定后再加。
- 以后再说：现在不设计，不为它预留复杂架构。
- 永久不做：至少第一年不碰，除非项目目标重写。

## MVP 的真实定义

MVP 不是“功能看起来很多”。ComicPlate 的 MVP 是：

1. 启动应用。
2. 选择一个图片文件夹。
3. 程序扫描并自然排序图片。
4. 显示第一张图。
5. 左右键翻页。
6. 支持双页和阅读方向。
7. 有基础目录侧栏。
8. 关闭后再次打开同一路径，可以恢复上次页。
9. 可以打开 ZIP/CBZ 并以同样方式阅读。

MVP 不包含：

- 设置窗口。
- 主题。
- 插件。
- 脚本。
- 复杂可停靠/拖拽组合面板。
- 书签。
- 文件管理。
- 导出。
