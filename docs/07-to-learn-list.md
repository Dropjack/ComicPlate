# To Learn List

To-Learn 是“你为了监督 Codex 和理解项目必须知道什么”。它不是系统学习 C# 的大课。

## 立刻要懂

### Avalonia 项目结构

你需要知道：

- `Program.cs` 是入口。
- `App.axaml` 放应用级资源。
- `MainWindow.axaml` 是主窗口 UI。
- ViewModel 保存界面状态。

够用标准：

- 你能说出“按钮在哪个文件，按钮点击后调用哪个 ViewModel 方法”。

### MVVM 最小用法

你需要知道：

- View 是界面。
- ViewModel 是状态和命令。
- Model/Core 是业务逻辑。

够用标准：

- 你能判断一段“扫描文件夹”的代码不应该写在按钮控件里面。

### 文件 IO

你需要知道：

- 如何判断路径存在。
- 如何枚举文件。
- 绝对路径和相对路径区别。
- 为什么要处理权限失败。

够用标准：

- 你能看懂“打开文件夹 -> 枚举图片 -> 排序”的代码。

### 自然排序

你需要知道：

- 字典序会把 `10.jpg` 排在 `2.jpg` 前面。
- 自然排序会按数字值比较。

够用标准：

- 你能用测试数据判断排序是否符合漫画阅读直觉。

### 图片解码和内存释放

你需要知道：

- 图片文件可能很大。
- 图片流要释放。
- 一次加载整本书会爆内存。

够用标准：

- 你能判断“把所有图片一次性读成 Bitmap”是危险路线。

## 第二阶段要懂

### JSON 配置

你需要知道：

- 设置和历史可以保存为 JSON。
- JSON 需要版本号。
- 读失败要有默认值。

够用标准：

- 你能打开 `settings.json` 看懂每个字段。

### C# async/await

你需要知道：

- 文件扫描和图片加载可能耗时。
- UI 线程不能被长任务卡住。
- `CancellationToken` 用于取消旧任务。

够用标准：

- 你能理解为什么打开大压缩包时不应该卡死窗口。

### ZIP 读取

你需要知道：

- ZIP 里有条目，不一定都是文件。
- 条目可能在子目录里。
- 条目流需要及时关闭。

够用标准：

- 你能检查“非图片忽略、图片排序、打不开时报错”是否都处理了。

## 打包前要懂

### Windows publish

你需要知道：

- Debug 运行和 Release 打包不同。
- 单文件发布、自包含发布会影响体积。

够用标准：

- 你能运行打包命令，并知道输出目录在哪里。

### macOS app bundle

你需要知道：

- macOS 应用通常是 `.app` bundle。
- 权限、签名、公证是后续问题。

够用标准：

- 你能在 macOS 上启动打包出来的应用。

### Git 分支与回滚

你需要知道：

- 每个阶段最好单独提交。
- 出错时可以看 diff。
- 不要混着改文档、架构、UI 大重构。

够用标准：

- 你能让 Codex 给你解释本次 diff 改了什么。

## 暂时不用学

现在不用学：

- WPF。
- NeeView 的完整实现。
- 插件系统。
- 脚本系统。
- 复杂命令系统。
- 主题格式。
- PDF 渲染。
- 视频播放。
- 数据库。

这些知识不但不帮 MVP，反而会把注意力带偏。
